# Tredjepartsdata

Landefakta i `src/data/wikidata-countries.generated.json` er hentet fra Wikidata
via Wikidata Query Service. Wikidatas strukturerede data er frigivet under
Creative Commons CC0 1.0 (public domain).

- Kilde: https://www.wikidata.org/
- Licens: https://creativecommons.org/publicdomain/zero/1.0/
- Opdatering: `npm run questions:update-wikidata`
